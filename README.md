# ЛР2. Трекинг плоского объекта по ключевым точкам

СКОиЗ. Степаненко В.П., P3432.

## 1. Теоретическая база

SIFT находит локальные особенности изображения в разных масштабах и описывает окрестность каждой точки вектором из 128 компонент. Масштаб и ориентация точки учитываются при построении дескриптора. Это помогает сопоставлять изображение объекта при изменениях размера и поворота. Сильное размытие и изменение ракурса снижают устойчивость.

Для каждого дескриптора эталона ищутся два ближайших дескриптора текущего кадра по расстоянию L2. Пара сохраняется, если первое расстояние меньше 0.75 второго. Так отбрасываются неоднозначные совпадения. Затем RANSAC оценивает гомографию и отсеивает пары, которые не согласуются с общим преобразованием плоскости.

Гомография задаётся матрицей 3×3 с восемью независимыми параметрами: $s(u,v,1)^T=H(x,y,1)^T$. Для её оценки нужны минимум четыре пары точек в невырожденной конфигурации. Углы эталонного прямоугольника переносятся через H в текущий кадр. Получается четырёхугольник, который учитывает перспективу.

Для сопровождения между соседними кадрами используется пирамидальный оптический поток Лукаса-Канаде. Он переносит локальные точки при предположении приблизительного постоянства яркости. Обратный перенос отбрасывает ненадёжные точки. Сопоставление с эталоном корректирует накопленную ошибку и восстанавливает трекинг после потери.

## 2. Описание разработанной системы

`track.py` читает видео через OpenCV. По умолчанию эталоном служит весь первый кадр. Параметр `--roi X Y W H` ограничивает эталон прямоугольником. ROI задаёт границы отслеживаемого объекта на первом кадре.

Эталонные дескрипторы SIFT вычисляются на пяти масштабах первого кадра: 1.0, 0.75, 0.5, 0.35 и 0.25. Координаты приводятся к исходному размеру. После BFMatcher и теста Лоу 0.75 дубли по точкам текущего кадра удаляются. Гомография оценивается RANSAC с порогом 2 пикселя. Требуются минимум 8 inliers, их доля не меньше 0.4 и достаточное пространственное покрытие объекта.

Между кадрами отслеживаются точки Ши-Томаси внутри текущей рамки. Поток Лукаса-Канаде проверяется прямым и обратным переносом с ошибкой меньше 0.8 пикселя. При 30 и более прошедших проверку точках оценивается межкадровая гомография; если она ненадёжна или точек меньше, используется аффинное преобразование с минимум 6 inliers. При малом размере объекта эта модель уменьшает число оцениваемых параметров.

Каждый пятый кадр, а также при потере потока выполняется поиск SIFT. Согласованная с потоком оценка корректирует углы рамки; при надёжном SIFT вес коррекции больше. Проверяются выпуклость, ориентация, площадь и длины сторон. В режиме потока и при коррекции ограничены межкадровое изменение площади и смещение углов. После потери допускается независимое повторное обнаружение.

Результат отмечается зелёной рамкой с подписью `Object`. В строке состояния указаны режимы INIT, FLOW, FLOW+SIFT, SIFT или LOST. При потере обеих оценок рамка не рисуется; последнее положение не замораживается.

Нужны Python 3, NumPy и OpenCV с SIFT. Проверено на OpenCV 5.0.0. Команды из папки лабы:

```powershell
python track.py videos/mona-lisa.avi
python track.py videos/mona-lisa-blur.avi
python track.py videos/mona-lisa-blur-extra-credit.avi
python track.py videos/own.mp4 --roi 125 300 470 720 --label Book
```

Исходные ролики лежат в `videos/`. Выходной каталог задаётся `--output`, подпись - `--label` (встроенный шрифт OpenCV поддерживает латиницу).

## 3. Результаты работы и тестирования системы

Тестирование 17.11.2026. Для роликов курса эталоном служит весь первый кадр; для собственной записи выбрана область обложки:

| Видео | Размер | Кадры | Рамка найдена | Пропуски | Обработка, кадр/с |
|---|---|---:|---:|---:|---:|
| mona-lisa.avi | 640×360 | 558 | 554 | 4 | 39.22 |
| mona-lisa-blur.avi | 640×360 | 558 | 535 | 23 | 39.52 |
| mona-lisa-blur-extra-credit.avi | 640×360 | 558 | 526 | 32 | 36.64 |
| own.mp4 | 720×1280 | 489 | 167 | 322 | 3.51 |

На участке отдаления камеры, кадры 150-389 включительно, во всех трёх роликах получено 240 обнаружений из 240. В обычном ролике пропущены кадры 475-478. В blur-версиях дополнительные потери возникают при сильном размытии; после восстановления признаков сопровождение возобновляется.

Для каждого теста в `results/` записаны обработанное видео `*_out.avi` с кодеком MJPG, покадровый CSV и JSON со сводкой. CSV содержит режим обработки, число точек потока, число пар SIFT и inliers, признак найденной рамки и координаты четырёх углов. В кадрах без запуска SIFT соответствующие счётчики равны нулю. В JSON средние matches и inliers вычислены только по кадрам с непустым набором пар SIFT. Первый кадр включён как инициализация. Скорость учитывает чтение, обработку и запись после подготовки эталона.

Результаты: [обычный ролик](results/mona-lisa_out.avi), [размытие](results/mona-lisa-blur_out.avi), [extra credit](results/mona-lisa-blur-extra-credit_out.avi), [собственная запись](results/own_out.avi).

На искусственной последовательности из 91 кадра с известным уменьшением масштаба и перспективным преобразованием средняя ошибка углов составила 0.24 пикселя, максимальная - 0.69 пикселя. На пустом кадре обнаружение отвергнуто, при возвращении эталона объект найден повторно. Все выходные тестовые видео повторно декодированы; число кадров совпало с CSV и JSON.

Просмотр контрольных кадров подтвердил сопровождение картины на дальнем участке. Полной ручной разметки нет: IoU и ошибка углов на реальных роликах не измерялись. Рамка соответствует области, видимой на первом кадре; обрезанные в эталоне части листа она не восстанавливает. 

Собственная запись `own.mp4` длится около 16.3 секунды и содержит 489 кадров размером 720×1280. Объект - обложка книги "Паттерны объектно-ориентированного проектирования". Камера отдаляется и меняет ракурс; на части кадров заметно размытие движения. На первом кадре выбрана прямоугольная область внутри обложки: x=125, y=300, ширина 470, высота 720 пикселей. Фон исключён из эталона. Рамка сопровождает эту область, а не полный внешний контур книги.

На собственной записи рамка найдена на 167 из 489 кадров (34.2%). На кадрах 115-428 происходит длительная потеря при косом ракурсе и движении камеры; перед потерей заметен перекос рамки. После возвращения к более близкому к исходному виду объект обнаруживается повторно. Подсчёт проверен по CSV; обработанное видео декодировано полностью, контрольные кадры просмотрены. Тест выявил ограничение устойчивости к изменению ракурса. Частота найденных рамок не заменяет измерение точности границ по ручной разметке.

## 4. Выводы по работе

Совместное использование SIFT и оптического потока сохраняет сопровождение при уменьшении объекта. В обычном ролике рамка найдена на 554 из 558 кадров, на участке отдаления пропусков нет. Периодическая привязка к эталону ограничивает дрейф, а аффинная модель движения используется при недостатке точек для устойчивой гомографии. Сильное размытие всё ещё приводит к кратковременным потерям. На собственной записи с изменением ракурса получено 167 обнаружений из 489; при косом ракурсе наблюдается длительная потеря. Непрерывное сопровождение в таких условиях не достигнуто. Точность границ зависит от исходной области и не оценивалась по ручной разметке.
